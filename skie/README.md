# Skie alliance website

A static OGame alliance website with shared, source-labeled guides.

This directory is separate from the original Project Orion guide at the repository root. All Orion root files remain unchanged.

Public content is in `data/content.json`; `assets/content.js` is the browser-ready copy. Keep these synchronized when editing.

Skie 0.1.0. The Orion calculator is a historical PTS v13.1.0 beta13 reference, not current live-universe pricing.

Project Orion source: https://github.com/TheIlluminate92/ogame-project-orion/tree/56a951bbeca850d00ff1ccca106b05475daa7fb3

No account integration or automatic Discord posting is enabled. Introduction text stays in browser memory and is not submitted.
